订单

订单是买方接受某一家对客价之后的承诺。询价到释放报价为止，见 询价。起息之后的观察、票息、敲出和到期，见 存续。谁能下单、谁能审批，见 用户角色。

从接受报价到起息

flowchart TD
  pick[买方选中一家已释放的对客价] --> size[写下名义金额和终端客户]
  size --> approve{这笔要不要内部审批}
  approve -->|要| gate{审批人是否通过}
  gate -->|否决| stop1[没有订单]
  gate -->|通过| look[发行商按当下市场做最后确认]
  approve -->|不要| look
  look --> result{确认结果}
  result -->|拒绝| stop2[没有持仓]
  result -->|价格变了| reprice[重报一档对客价，买方重新决定]
  reprice --> pick
  result -->|确认成交| lock[发行商、条款、对客价、名义金额锁定]
  lock --> settle[运营发出成交确认和托管指令]
  settle --> live[到起息日，持仓交给存续]

一笔询价通常落成一家发行商的一张订单。买方看见的是已经加上 UF 的对客价。发行商最后确认时，市场若已经走开，可以重报，也可以拒绝。重报等于一档新的对客价，买方要重新接受。审批人可以否决这笔订单，不改价格。

成交当时锁定的是商业条款。观察日的敲出、敲入和票息还不存在，那些等计算代理人在存续里逐次确认。运营在成交后核对名义金额、交割日、托管账户，把资金或日后可能交来的股票落到终端客户名下。

一张订单上有什么

锁定的内容业务含义
产品和全部条款标的、期限、敲出、敲入、执行价、求解出来的那个数。成交后不再改结构
发行商出票的那一家。其他家的报价不再使用
对客价买方实际买入价。票据是票面价或发行价，AQ / DQ 是执行价加上已经谈妥的 UF
名义金额或每日股数票据写名义本金。累计期权写每天买卖多少股，杠杆日按倍数放大
终端客户和托管行钱和股票落在谁的账户。买方机构是下单的人，终端客户是这笔头寸的主人

订单从哪来

来源条款从哪来之后怎么进存续
询价接受买方接受分销台释放的某一家对客价成交并起息后，按这套条款开始观察
外面已经谈妥电话或邮件里条款和价格都定了，再记进订单同样从起息开始。少了一次系统里的多家比价
已发行票据再卖出条款和 ISIN 来自一张已经在存续中的票据买方买的是剩余期限，观察日接着原来的日历走，不重新询一个求解项

成交之后，交易台不再改这张单的价格。存续运营跟踪观察日，收入岗位按这笔 UF 和返佣记账。官方敲出水平和票息金额以发行商担任的计算代理人为准。
